# Claude a Fondo

Curso práctico para aprender a usar Claude: pedidos, proyectos, memoria, archivos, artefactos, búsqueda, conectores, navegador, skills, tareas programadas y Claude Code.

Se instala como app en el celular y en la compu (Chrome o Edge: menú → "Instalar app" / "Agregar a la pantalla principal").
App: https://gulecar1971.github.io/claude-a-fondo/
